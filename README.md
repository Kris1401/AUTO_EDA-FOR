# AUTO EDA FOR — MVP (Etap 0)

Szkielet aplikacji Streamlit z i18n, walidacją konfiguracji, motywem i nawigacją (PL/EN).
Kolory wyekstrahowano z dostarczonej grafiki.

## Uruchomienie lokalne
```bash
python -m venv .venv   # Windows: .venv\Scripts\activate
pip install -r requirements.txt
streamlit run app/app.py
```
